# BAD LIE — asset and licence record

Every asset in the game is listed here with its origin and licence. Apart from the two
fonts and Unity's own packages, everything was made for this project, either by code in this
repository or generated by scripts in `Tools/`. No third-party art, sound, music, store assets
or AI image generators were used.

## Fonts (third party, SIL Open Font License 1.1)

| File | Use | Source | Licence |
|---|---|---|---|
| `Assets/BadLie/Fonts/Cinzel.ttf` | Titles, hole names (tracked serif capitals) | The Cinzel Project Authors, https://github.com/NDISCOVER/Cinzel | OFL 1.1, text in `Cinzel-OFL.txt` |
| `Assets/BadLie/Fonts/BarlowSemiCondensed-Medium.ttf` | Numbers, body text | The Barlow Project Authors, https://github.com/jpt/barlow | OFL 1.1, text in `BarlowSemiCondensed-OFL.txt` |

The OFL allows bundling the fonts in a game. The licence texts ship next to the font files.
The fonts are not sold on their own and keep their names.

## Reference images

The three reference images in the brief (Death's Door, COCOON, Hades II) were used only for
visual analysis (`Docs/ArtDirection.md`). Nothing from them is copied into the game. No
names, logos, characters or assets from those games appear in BAD LIE.
